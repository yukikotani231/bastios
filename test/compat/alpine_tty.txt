# Programs driven by keystrokes on the console inside the Alpine root, for
# the compatibility suite (test/compat). The format is tty.txt's. They run
# after alpine.txt in the same guest, so the packages its cases installed
# are there (gcc among them). The Bastio toolchain (bastioc1, Z3, tcc:
# bastiotools.sh) is on this disk too, outside the Alpine root.

== tmux: attach on the console, run a command in the session, detach and find it still there
$ test -x /disk/a/usr/bin/tmux && bb mount --bind /dev /disk/a/dev && bb mount --bind /dev/pts /disk/a/dev/pts; bb chroot /disk/a /bin/sh -c 'export TERM=xterm; tmux -f /dev/null new-session -s t sh'
> echo $((40 + 2)) > /root/tt.txt\r
> \x02d
$ bb chroot /disk/a /bin/sh -c 'export TERM=xterm; tmux ls | cut -c1-12; cat /root/tt.txt; tmux kill-server >/dev/null 2>&1'; bb umount /disk/a/dev/pts; bb umount /disk/a/dev
t: 1 windows
42

== nvim: edit a Bastio program, prove and build it, run it
