# Lua and LuaRocks on BastiOS, for the compatibility suite (test/compat): the
# Lua 5.4 interpreter and LuaRocks of an Alpine-based image (with gcc and
# musl, which rocks with C modules are built with), entered with chroot. The
# Lua disk (scriptdisk.py) holds the image's root as a tar file
# (/disk/root.tar) and a BusyBox at /disk/busybox. The format is
# applets.txt's:
#
#   == NAME
#   $ COMMAND        (one line, run by ash in /)
#   expected output, line by line, compared exactly
#
# The expected output is what Linux prints for the same commands in a chroot
# of the same root.
