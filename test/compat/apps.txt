# Real programs for the compatibility suite (test/compat), built by the
# Makefile from their own sources: Lua, QuickJS and the sqlite3 shell.
# The format is applets.txt's:
#
#   == NAME
#   $ COMMAND        (one line, run by ash in /)
#   expected output, line by line, compared exactly
#
# Keep files a case makes under names starting with "ca_" and remove them
# in the same command.

== lua: arithmetic and strings

== lua: coroutines and tables

== sqlite3: 20000 rows, an index and a query

== micropython: classes, generators, exceptions, big integers

== micropython: threads and a lock
$ printf 'import _thread, time\ndef w(k, lock, done):\n    with lock: done.append(k)\nlock = _thread.allocate_lock()\ndone = []\nfor k in range(4): _thread.start_new_thread(w, (k, lock, done))\nt0 = time.time()\nwhile len(done) < 4 and time.time() - t0 < 5: time.sleep_ms(10)\nprint("threads", sorted(done))\n' > ca_t.py && /disk/micropython ca_t.py; rm -f ca_t.py

== httpd: serve a page, fetch it over loopback

wget: server returned error: HTTP/1.1 404 Not Found
status 1
