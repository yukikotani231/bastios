# Debian on BastiOS, for the compatibility suite (test/compat): Debian's
# root file system unpacked on the disk and entered with chroot, where its
# programs run. They are linked against glibc, so each starts in glibc's
# dynamic linker, /lib64/ld-linux-x86-64.so.2 (on AArch64 /lib/ld-linux-aarch64.so.1):
# a link to a link, which the kernel follows from inside the chroot. The Debian disk (debiandisk.py)
# holds the root as /disk/root.tar and a BusyBox as /disk/busybox; the
# suite boots it separately. The format is applets.txt's:
#
#   == NAME
#   $ COMMAND        (one line, run by ash in /)
#   expected output, line by line, compared exactly
#
# %GLIBCLD%, %MULTIARCH% and %MACHINE% stand for the dynamic linker's path, the
# library directory's name and uname -m on the guest's processor.
#
# The cases run in order: the first unpacks the root. The expected output
# is what Linux prints for the same commands in a chroot of the same root.

== debian: unpack the root, chroot into it
$ mkdir -p /disk/d && cd /disk/d && bb tar -xf /disk/root.tar && for d in null:1:3 zero:1:5 random:1:8 urandom:1:9 tty:5:0 console:5:1; do set -- $(echo $d | bb tr : ' '); bb mknod dev/$1 c $2 $3; done; cd /; bb chroot /disk/d /usr/bin/true; echo status $?; bb cat /disk/d/etc/debian_version
status 0
13.7

== debian: the dynamic linker through its links, by hand
$ bb chroot /disk/d %GLIBCLD% --list /usr/bin/true | bb sed 's/ (0x[0-9a-f]*)//' | bb tr -d '\t'
linux-vdso.so.1
libc.so.6 => /lib/%MULTIARCH%/libc.so.6
%GLIBCLD%

== debian: bash
$ bb chroot /disk/d /bin/bash -c 'x=(a b c); echo ${#x[@]} ${x[1]} $((6 * 7)); [[ abc == a* ]] && echo match; echo ${BASH_VERSINFO[0]}'
3 b 42
match
5

== debian: coreutils make, copy, move, link and look at files
$ bb chroot /disk/d /bin/bash -c 'cd /tmp && echo hello > f && cp f g && mv g h && ln -s h l && readlink l && cat l && stat -c "%s %F" h && ls -1 l h && rm f h l && ls'
h
hello
6 regular file
h
l

== debian: find, xargs and du
$ bb chroot /disk/d /bin/bash -c 'find /etc -maxdepth 1 -name "pass*" | sort | xargs -n1 basename; du -s /etc > /dev/null && echo du ok'
passwd
passwd-
du ok

== debian: users and the machine

== debian: perl
