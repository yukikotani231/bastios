# Node.js on BastiOS, for the compatibility suite (test/compat): the Node
# binary of the official node:alpine image, entered with chroot. It is a
# dynamically linked musl program (libstdc++, libgcc) with V8 inside, which
# maps a large range of address space at start and generates machine code
# at run time. The Node disk (nodedisk.py) holds the root as /disk/n and a
# BusyBox as /disk/busybox; the suite boots it separately. The format is
# applets.txt's:
#
#   == NAME
#   $ COMMAND        (one line, run by ash in /)
#   expected output, line by line, compared exactly
#
# The expected output is what Linux prints for the same commands in a chroot
# of the same root.

== node: make the device nodes
$ cd /disk/n && bb mkdir -p dev proc tmp etc; for d in null:1:3 zero:1:5 random:1:8 urandom:1:9 tty:5:0 console:5:1; do set -- $(echo $d | bb tr : ' '); bb mknod dev/$1 c $2 $3; done; cd /; bb ls /disk/n/dev | bb cat
console
null
random
tty
urandom
zero

== node: version
$ bb chroot /disk/n /usr/local/bin/node --version
v22.23.3

== node: an expression
$ bb chroot /disk/n /usr/local/bin/node -p '6 * 7' | bb cat
42

== node: a script with arrays and JSON
$ bb chroot /disk/n /usr/local/bin/node -e 'console.log([3,1,2].sort().join(" "), JSON.stringify({x: 1}))' | bb cat
1 2 3 {"x":1}

== node: timers and promises run in order
$ bb chroot /disk/n /usr/local/bin/node -e 'setTimeout(() => console.log("timer"), 20); Promise.resolve().then(() => console.log("promise")); process.nextTick(() => console.log("tick")); console.log("sync")' | bb cat
sync
tick
promise
timer

== node: read and write files
$ bb chroot /disk/n /usr/local/bin/node -e 'const fs = require("fs"); fs.writeFileSync("/tmp/n.txt", "hello\n"); fs.appendFileSync("/tmp/n.txt", "world\n"); console.log(fs.readFileSync("/tmp/n.txt", "utf8").split("\n").length, fs.statSync("/tmp/n.txt").size)' | bb cat
3 12

== node: a hot loop is compiled and gives the right sum
$ bb chroot /disk/n /usr/local/bin/node -e 'let s = 0; for (let i = 0; i < 5000000; i++) s += i % 7; console.log(s)' | bb cat
14999995

== node: exit status and uncaught exceptions
$ bb chroot /disk/n /usr/local/bin/node -e 'process.exit(3)'; echo status $?
status 3

== node: a real package (nanoid) fetched from the host, tested with node --test
# timeout 300
$ bb mkdir -p /disk/n/work; bb wget -q -O - HOSTURL/oss/nanoid.tar.gz | bb tar -xz -C /disk/n/work && bb chroot /disk/n /usr/local/bin/node --test /work/nanoid/test/index.test.js /work/nanoid/test/non-secure.test.js 2>&1 | bb grep -E '^# (tests|pass|fail)'
# tests 34
# pass 34
# fail 0

== node: a real package (debug) with its installed dependencies, tested with mocha and sinon
