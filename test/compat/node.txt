# Node.js on BastiOS, for the compatibility suite (test/compat): the Node
# binary of the official node:alpine image, entered with chroot. It is a
# dynamically linked musl program (libstdc++, libgcc) with V8 inside, which
# maps a large range of address space at start and generates machine code
# at run time. The Node disk (nodedisk.py) holds the root as /disk/n and a
# BusyBox as /disk/busybox; the suite boots it separately. The format is
# applets.txt's:
#
#   == NAME
#   $ COMMAND        (one line, run by ash in /)
#   expected output, line by line, compared exactly
#
# The expected output is what Linux prints for the same commands in a chroot
# of the same root.

== node: make the device nodes
$ cd /disk/n && bb mkdir -p dev proc tmp etc; for d in null:1:3 zero:1:5 random:1:8 urandom:1:9 tty:5:0 console:5:1; do set -- $(echo $d | bb tr : ' '); bb mknod dev/$1 c $2 $3; done; cd /; bb ls /disk/n/dev | bb cat
console
null
random
tty
urandom
zero

== node: a script with arrays and JSON

== node: timers and promises run in order
$ bb chroot /disk/n /usr/local/bin/node -e 'setTimeout(() => console.log("timer"), 20); Promise.resolve().then(() => console.log("promise")); process.nextTick(() => console.log("tick")); console.log("sync")' | bb cat

tick
promise
timer
