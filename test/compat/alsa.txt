# Sound on BastiOS, for the compatibility suite (test/compat): Ubuntu's
# alsa-utils and alsa-lib, linked against glibc, entered with chroot and
# playing on the HD Audio card the lane's guest has (QEMU's intel-hda with
# its output discarded; test/shell_test.sh checks the samples that reach the
# card). The ALSA disk (alsadisk.py) holds the root as /disk/root.tar and
# a BusyBox as /disk/busybox. The format is applets.txt's:
#
#   == NAME
#   $ COMMAND        (one line, run by ash in /)
#   expected output, line by line, compared exactly
#
# The cases run in order: the first unpacks the root.

== alsa: unpack the root, make the device nodes
$ mkdir -p /disk/s && cd /disk/s && bb tar -xf /disk/root.tar && for d in null:1:3 zero:1:5; do set -- $(echo $d | bb tr : ' '); bb mknod dev/$1 c $2 $3; done; bb mkdir dev/snd; bb mknod dev/snd/controlC0 c 116 0; bb mknod dev/snd/pcmC0D0p c 116 16; bb chmod 666 dev/null dev/zero dev/snd/*; cd /; bb chroot /disk/s /usr/bin/aplay --version; echo status $?
aplay: version 1.2.9 by Jaroslav Kysela <perex@perex.cz>
status 0

== alsa: aplay lists the card
$ bb chroot /disk/s /usr/bin/aplay -l
**** List of PLAYBACK Hardware Devices ****
card 0: HDA [BastiOS HD Audio], device 0: HDA [BastiOS HD Audio]
  Subdevices: 1/1
  Subdevice #0: subdevice #0

== alsa: aplay plays mono 24 kHz on the hardware device
$ bb chroot /disk/s /usr/bin/aplay -D hw:0,0 -d 1 -f S16_LE -r 24000 -c 1 /dev/zero 2>&1; echo status $?
Playing raw data '/dev/zero' : Signed 16 bit Little Endian, Rate 24000 Hz, Mono
status 0

== alsa: aplay plays through mmap
$ bb chroot /disk/s /usr/bin/aplay -D hw:0,0 -M -d 1 -f S16_LE -r 24000 -c 1 /dev/zero 2>&1; echo status $?
Playing raw data '/dev/zero' : Signed 16 bit Little Endian, Rate 24000 Hz, Mono
status 0

== alsa: the default device converts the format and the rate
$ bb chroot /disk/s /usr/bin/aplay -d 1 -f U8 -r 11025 -c 2 /dev/zero 2>&1; echo status $?
Playing raw data '/dev/zero' : Unsigned 8 bit, Rate 11025 Hz, Stereo
status 0

== alsa: amixer lists the volume control
$ bb chroot /disk/s /usr/bin/amixer controls; bb chroot /disk/s /usr/bin/amixer cset numid=1 200,100 >/dev/null; bb chroot /disk/s /usr/bin/amixer cget numid=1 | bb grep ': values'
numid=1,iface=MIXER,name='PCM Playback Volume'
  : values=200,100

== alsa: speaker-test plays a sine wave
$ bb chroot /disk/s /usr/bin/speaker-test -t sine -f 1000 -l 1 -c 2 2>&1 | bb grep -c 'Front'; bb chroot /disk/s /usr/bin/speaker-test -t sine -f 1000 -l 1 -c 2 >/dev/null 2>&1; echo status $?
2
status 0

== alsa: SDL2 plays through its ALSA backend
$ SDL_AUDIODRIVER=alsa bb chroot /disk/s /usr/bin/sdlbeep 2>&1; echo status $?
sdlbeep: driver alsa, 48000 Hz, 2 channels
sdlbeep: ok
status 0
