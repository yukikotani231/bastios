# Perl on BastiOS, for the compatibility suite (test/compat): the perl of an
# Alpine-based image (with the core modules), entered with chroot, and a
# subset of the perl5 test suite (t/ of the release tarball, run with the
# image's perl). The Perl disk (perldisk.py) holds the image's root as a tar
# file (/disk/root.tar), a BusyBox at /disk/busybox and the tests under /work/p
# in the root. The format is applets.txt's:
#
#   == NAME
#   $ COMMAND        (one line, run by ash in /)
#   expected output, line by line, compared exactly
#
# The expected output is what Linux prints for the same commands in a chroot
# of the same root. A test group prints "ran N" when none of its N tests fails
# (perl-tests.txt lists the tests that pass on Linux and on BastiOS).
