# Ruby on BastiOS, for the compatibility suite (test/compat): ruby, irb, gem,
# rake and the bundled gems of the official ruby:alpine image, entered with
# chroot. The Ruby disk (rubydisk.py) holds the image's root as a tar file
# (/disk/root.tar) and a BusyBox at /disk/busybox. The format is applets.txt's:
#
#   == NAME
#   $ COMMAND        (one line, run by ash in /)
#   expected output, line by line, compared exactly
#
# The expected output is what Linux prints for the same commands in a chroot
# of the same root.

== ruby: unpack the root, make the device nodes
$ bb mkdir -p /disk/r && cd /disk/r && bb tar -xf /disk/root.tar && bb mkdir -p proc tmp work && for d in null:1:3 zero:1:5 random:1:8 urandom:1:9 tty:5:0 console:5:1; do set -- $(echo $d | bb tr : ' '); bb mknod dev/$1 c $2 $3; done; cd /; bb mount -t proc proc /disk/r/proc; bb ls /disk/r/dev | bb cat

== ruby: a real project (rexml) tested with its own test suite
# The parse/ tests need core_assertions, a helper of Ruby's own test tree that no gem carries: left out.
